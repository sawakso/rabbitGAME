# rabbitGAME · 最后一格

一个**单文件 HTML 小游戏**：在棋盘上走一条不能回头的路，别把自己困住。

纯静态、零依赖，双击 `index.html` 就能玩，也适合直接内嵌进微信小程序 `web-view` 或打成小游戏包体。

---

## 在线试玩

> GitHub Pages 开启后把地址填到这里，例如 `https://sawakso.github.io/rabbitGAME/`

## 玩法

1. 点任意一格落子。
2. 之后只能走**上下左右相邻**的格子。
3. 走过的格子会变粉，**不能回头**。
4. 颜色预告未来三步：<kbd>黄</kbd>=下一步　<kbd>米</kbd>=第 2 步　<kbd>灰</kbd>=第 3 步，格子右上角还会标出 1 / 2 / 3。
5. 每个黄色格**右下角的数字**是「走这里之后还剩多少互通空地」——**数字越大越安全**，这是这个游戏的核心判断依据。
6. 走到目标步数即通关；把自己走进死胡同就结束。

## 功能

| 分类 | 内容 |
| --- | --- |
| 难度 | 轻松 6×6 / 18 步　标准 8×8 / 26 步　挑战 8×8 / 30 步 |
| 模式 | 常规随机地图 + **每日挑战**（同一天全服同一张图，日期做种子） |
| 辅助 | 悔棋（每局 3/3/2 次）、提示（高亮最优走法）、活路数字开关 |
| 记录 | 各难度最高步数，存 `localStorage` |
| 操作 | 触屏点击；键盘方向键走子、`U` 悔棋、`H` 提示、`R` 换局 |

## 画面与声音

- **背景**：暖色黄昏渐变、太阳光晕、缓慢摇摆的云、三层远山与松树剪影、上浮光点。
- **角色**：兔子是纯 SVG 手绘的，会随状态切换表情（平静 / 眯眼笑 / 紧张 / 哭）；另有一只迷你兔会跳到当前格上。
- **棋盘**：走过的路径用粉色虚线连起来，每格标出步数序号。
- **音乐**：**Web Audio 实时合成**的八音盒 BGM —— C–G–Am–F 四小节循环，正弦基音加高八度泛音做八音盒音色，过延时反馈当轻混响，62 BPM。
  走子音效沿五声音阶随步数上行，越走越亮；通关是上行琶音，死胡同是下行两音。
  **没有任何音频文件**，所以零版权风险、断网可用、不增加包体。

## 运行

直接双击打开：

```
index.html
```

或起一个静态服务（可选，用于手机局域网调试）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署

### GitHub Pages

`Settings` → `Pages` → `Source` 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → 保存。
一两分钟后访问 `https://sawakso.github.io/rabbitGAME/`。

### Cloudflare Pages

`Workers & Pages` → `Create` → `Pages` → 连接本仓库：
构建命令**留空**，输出目录填 `/`。或者直接把仓库根目录拖拽上传。

> 注意：`*.pages.dev` 和 `*.github.io` 在中国大陆访问经常偏慢。
> 面向国内用户建议改用腾讯云 COS + CDN、EdgeOne Pages、阿里云 OSS，
> 或者干脆把这个 48KB 的文件直接打进小游戏包体，连网络请求都省了。

## 技术说明

- **零外部依赖**：没有 CDN、没有外链字体、没有图片文件、没有音频文件，CSS / JS / SVG / 音乐全部内联或实时合成。
- `index.html` 单文件 48 KB，gzip 后约 **15 KB**。
- 竖屏优先，已适配 `env(safe-area-inset-*)` 安全区；`390×844` 与 `360×780` 均实测无横向溢出。
- 地图生成会校验「起点四邻可达 + 连通空地 ≥ 目标步数」，不会开出死图。
- 每日挑战用 `mulberry32` 以日期为种子，保证同一天同一张地图。

## 操作提示

- 卡住了先点「悔棋」，不要硬走。
- 「提示」会高亮当前最优的一步，额度有限，留在后半段用更值。
- 想挑战高分可以关掉「活路数字」，纯凭三步预告判断。
